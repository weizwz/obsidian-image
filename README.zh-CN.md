# Obsidian Image Manager

[English](./README.md) | [简体中文](./README.zh-CN.md)

一款轻量、高性能的 [Obsidian](https://obsidian.md) 桌面端图片管理插件。基于浏览器原生硬件加速 `OffscreenCanvas`，无需安装任何外部二进制依赖（如 `sharp` 或 `ffmpeg`），即可自动对粘贴、拖拽及库内已有图片进行重命名、归档移动、格式转换与尺寸压缩。

## 核心功能

- **粘贴与拖拽无感处理**：自动拦截编辑器中粘贴或拖入的图片，按预设规则完成格式转换、压缩、目录归档与重命名，并自动插入笔记链接。
- **硬件加速转换与压缩**：
  - 支持转换为 `WebP`、`JPEG`、`PNG` 或保持原格式。
  - 支持自定义压缩质量（`1–100`）、最大像素宽度与最大像素高度限制。
  - **体积保护（跳过变大结果）**：若转换或压缩后的文件体积大于原图，自动保留原图。
  - **智能跳过**：自动识别并跳过动态 GIF、SVG 矢量图及视频文件的重编码。
- **灵活的路径与命名模板**：
  - **目标文件夹变量**：`${noteName}`（笔记名称）、`${noteFolder}`（笔记所在目录）、`${date:YYYY-MM-DD}`（自定义格式日期）、`${year}`、`${month}`、`${day}`。
  - **文件名变量**：`${noteName}`、`${originalName}`（原文件名）、`${timestamp}`（时间戳）、`${date:YYYYMMDDHHmmss}`、`${hash:8}`（SHA-256 哈希前缀，支持自定义长度）。
  - 自动创建不存在的目标文件夹，并在文件名冲突时自动追加递增后缀（`-1`、`-2` 等）。
- **批量处理与全库统计**：
  - 支持按 **当前笔记** 或 **全库笔记** 批量处理被引用的本地图片（未被任何笔记引用的孤立图片会自动跳过）。
  - 三种批量处理模式：**修改图片名称和位置**、**转换图片格式并压缩**、**同时执行命名移动与转换压缩**。
  - 提供执行前确认弹窗、实时处理进度条以及 **安全停止** 功能。
  - 自动同步更新相关笔记中的内部链接（支持 Wiki 链接与 Markdown 链接），被替换的原文件自动移入 `.trash` 回收站以备恢复。
  - 设置页内置实时统计面板，直观展示当前笔记与全库引用图片数量、未引用图片数量及占用空间。
- **异常中断校验与恢复**：
  - 内置事务日志保护，若处理过程中遇意外断电或强制关闭，重启 Obsidian 时或通过设置页按钮即可一键回滚修复未完成的图片事务。
- **多语言支持（i18n）**：
  - 内置 **简体中文** 与 **English**，支持默认跟随 Obsidian 语言或手动切换。

## 命令列表

| 命令名称 | 说明 |
| :--- | :--- |
| **批量处理当前笔记中的图片** | 扫描并批量处理当前活动 Markdown 笔记中引用的所有本地图片。 |
| **处理当前行的图片** | 处理编辑器当前光标所在行的单张图片。 |

## 安装说明

### 手动安装

1. 构建本项目或从 Release 下载最新产物（`main.js`、`manifest.json`、`styles.css`）。
2. 将文件复制到你的 Obsidian 库插件目录：
   ```text
   <Vault>/.obsidian/plugins/image-manager/
   ```
3. 重新加载 Obsidian，并在 **设置 → 第三方插件** 中启用 **Image Manager**。

## 本地开发

```bash
# 安装依赖
npm install

# 启动开发监听编译
npm run dev

# 生产环境构建与类型检查
npm run build

# 运行代码规范检查
npm run lint
```
